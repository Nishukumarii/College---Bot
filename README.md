College---Bot

AI-Powered College Assistant

About the Project

CollegeBot is an AI-powered college assistant designed to help students access college-related information easily.

Objectives

- Answer college-related questions.
- Help students find academic information.
- Provide useful college updates.

Features

- Frequently Asked Questions (FAQs)
- Timetable information
- College announcements
- AI-powered assistance

Technologies Used

- Frontend: React.js, JavaScript, HTML, CSS
- Development Tool: Vite
- Backend: Python, Flask (if used)
- AI Integration: Google Gemini API (if integrated)
- AI Coding Tool: Google Antigravity IDE

Completed ✅
